# Lexicon

> A lightning-fast, minimalist Android launcher inspired by ergonomic vertical design, lightning-fast alphabetical indexing, and distraction-free home screens.

![Banner or Screenshot Placeholder](path/to/screenshot.png)

## ✨ Features

- **Ergonomic Vertical Layout**: Single-page home screen designed for effortless one-handed thumb reach.
- **Fluid Wave Index**: Instant alphabetical scrolling to navigate your entire app drawer in milliseconds.
- **Inline Notifications**: Read and reply to messages directly from your home screen.
- **Lightweight & Battery Efficient**: Built with performance-first principles to keep overhead minimal.
- **Zero Bloat**: Open-source, ad-free, and privacy-focused.

## 🛠️ Tech Stack & Architecture

- **Language**: Kotlin / Jetpack Compose
- **Architecture**: MVVM (Model-View-ViewModel) with Clean Architecture principles
- **Core APIs**: Android Accessibility & NotificationListenerService (for inline interactions), LauncherApps API
